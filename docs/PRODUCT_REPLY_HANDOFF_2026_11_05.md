### LX04 更新确认实机验收

原厂 APK 的 `SpeechExpectSpeechOperation.onProcess()` 会调用 `SpeechManager.setWakeup()`。`SpeechManager.setUnWakeup()` 是取消收音的候选入口，调用时机和对其他对话的影响仍需实机验证。更新确认只接续一次，并在询问播报实际结束后开启收音。

APK 中的 `SpeechSynthesizerCapabilityImpl.onPlayFinish()` 记录的是 TTS 末包并向播放器发送消息。续听验收应使用实际播放结束信号。原厂 `setUnWakeup()` 在对话模式下还会停止语音引擎，验收需覆盖上一轮超时和新唤醒重叠的情况，确认旧轮清理不会关闭新会话。

| 场景 | 预期结果 |
| --- | --- |
| 检查到已签名的新版本 | 播报「发现新版本，是否更新？」播报结束后短时收音一次，无需再次唤醒。 |
| 收音窗口内回答「更新」或「立即更新」 | 只确认一次，下载并验证已确认的版本，等待空闲安装。「立即升级」是唤醒后的独立口令。 |
| 回答「取消」、超时、门铃打断或重新唤醒 | 结束本次确认。后续单说「更新」不会确认这次安装。 |
| 当前已是最新版或检查失败 | 播报对应结果后结束。 |
| 小爱普通问答、购物追问或设备控制 | 原厂照常处理。 |
