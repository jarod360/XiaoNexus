# LX04 管理页与在线升级交接

基线为 V51.6.0-RC。先读 `CURRENT_STATE.md`、`RESIDENT_V51_6_0_RC_HANDOFF.md` 和 `BUILD_VARIANTS.md`。现网长时检查见下文。新功能应从此基线另行开发，实机通过后再发布。

## 首版目标

- 小爱本机提供简洁的管理网页，沿用现有模型接口。网页和更新器不依赖 HA。默认仅回环访问，电脑可通过 ADB 转发访问。
- 首次安装提供固定的初始管理密码，安装说明注明密码。首次登录提示设置并妥善保存新密码，改密后才允许修改规则或执行升级。使用独立的带盐密码哈希和有期限的会话，改密使旧会话失效。管理密码与 Agent 控制令牌分别保存。
- 网页支持启用和停止 AI 接管、查看有界脱敏日志、测试并保存漏拦截话术、补充上一轮短语和直接转 AI 的前缀。停止接管时管理入口仍可用。
- 漏拦截匹配原厂回复，补充短语要求可关联的上一轮，直接转 AI 用明确前缀。保留同轮 dialog ID、来源、播放 Owner、门铃抢占等原厂安全门控。单独验证直转不会和原厂播报或设备动作并行。
- 网页可检查并触发更新。唤醒后的专用短语分别触发检查与升级。更新器只接受固定仓库的已签名 LX04 对应版本、架构和构建类型；签名、公钥、文件摘要、版本和空间均验证后暂存。空闲时原子切换，启动失败自动回退，配置和密钥独立保留。旧版需经 ADB 安装一次新启动器。

## 代码与验证入口

- `runtime/device-agent/main.go` 已有回环 HTTP 服务、取消和门铃状态，适合复用同一进程。`scripts/prepare-legacy-variants.py` 只复制显式列出的运行时文件，新文件需加入构建清单。
- `runtime/device-supervisor/main.go` 负责最终 ASR、上一轮知识和 ARM。`runtime/frida/lx04_nexus_gate.js` 对完整原厂回复和本轮音频任务匹配。规则更新需保持原子性，验证未知或无效配置时的行为。
- `scripts/Install_Resident_LX04.ps1` 有暂存和 SHA-256 检查。在线升级尚未实现，发布签名密钥只能留在私有签名环境。
- 测试密码与会话、三类规则、正常原厂功能、门铃、语音升级、断网、错误包、断电或重启后的回滚。用同一实机采样新旧 CPU、内存和日志增长后再发布。

## 2026-11-07 基线

LX04 主进程连续运行约 64 小时，Agent、Supervisor 与 Frida 合计 RSS 约 50 MiB，20 秒 CPU 约为单核 5.7%。Supervisor 和 Frida 连续运行约 41 小时。EFS 本轮实际磁盘写入增量为零，Supervisor 日志约 81 KiB。发现 21 个原厂主进程已退出的子进程，短期计数未增加。详见当前会话的实机检查。

每个可验证阶段更新本交接，记录源提交、产物摘要、实测和回退方式。优先短小的本地验证，保留设备的现网 RC 作为对照。
